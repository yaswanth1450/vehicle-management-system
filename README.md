Vehicle Rental Management System – Project Overview 1. Project Overview The Vehicle Rental Management System is a Python-based application designed to manage vehicle rentals efficiently. It allows users to view available vehicles, register and manage customer details, rent vehicles, and track rental and return records. 2. Project Objective The main objective is to simplify the vehicle rental process, reduce manual record keeping, maintain accurate rental information, and make vehicle availability and rental status easy to track. 3. Technologies Used * Programming Language: Python * Data Storage: Python lists and dictionaries (in-memory storage) * Concepts: Functions, loops, conditional statements, exception handling, and data structures 4. Main Features * Vehicle Management: Stores vehicle IDs, names, rental prices, and availability. * Customer Management: Maintains customer information and IDs. * Vehicle Rental: Allows users to select a vehicle, enter a customer ID, and specify rental duration. * Rental Tracking: Records active and completed rentals. * Vehicle Return: Updates rental status and vehicle availability after a return. * Dashboard: Displays available vehicles, active rentals, and returned rentals. * Input Validation: Uses exception handling to manage invalid numerical input. 5. Working Process 1. The user opens the application. 2. The system displays the available menu options.
